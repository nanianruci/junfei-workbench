# Listing Studio 本地开发版

当前按模块维护，代码入口、数据边界和针对性检查见 [模块维护索引](MODULES.md)，本目录执行规范见 [AGENTS.md](AGENTS.md)。本页保留早期版本说明，实际业务行为以当前代码、用户最新要求和现行维护规范为准。

源码安装、Python 3.12 依赖和前端构建见[项目根 README](../../README.md)。安装后从项目根启动 `desktop_launcher.py`，源码默认地址为 `http://127.0.0.1:18769`。

出图先在图片工作台选真实素材并运行「AI 分镜」。确认分镜后从卡片或整套入口出图，换色沿用已完成母版的分镜。服务端在提交生成和返修前核对当前账号、产品和图位的分镜记录。旧记录仍可查询，没有 AI 分镜凭据的旧方案须重新策划后才能发起新生图。

产品库勾选多款后可批量删除。确认清单后，产品进入“已删除产品”，可恢复。已有全部子 SKU 在售核验的产品显示“已发布 · 站点”，点击可查看店铺、父 ASIN、任务号和核实时间。

原来的 HTML 文件仍可离线打开，但数据库、素材上传和模型功能需要通过上述 HTTP 地址使用。服务仅监听本机，尚未提供局域网或互联网访问。

## 已实现

- 服装、日用百货示例产品；搜索、筛选、新建父产品。
- 美英站文案独立编辑，字符与 UTF-8 字节计数，中文对照。
- 七张图片的方案编辑，使用明确标记的矢量占位图。
- 文案与图片分别确认、审核通过、附带意见退回。
- 当前站点文案 TXT 导出、产品资料 CSV 字段模板下载。
- SQLite 服务端保存，以及浏览器 localStorage 备份；首次运行从当前浏览器备份或示例数据初始化数据库。
- 保存版本号检查：其他页面修改后拒绝覆盖，提供本页 JSON 备份下载。备份导入尚未实现。
- 产品材质、尺寸、包装、品牌、关键词、颜色与尺码编辑。
- JPG、PNG、WebP 真实素材上传（每张最多 15 MB），记录来源和对应颜色。
- DeepSeek 文案模型配置与当前站点生成；需先填写材质、尺寸和包装内容。
- 模型生成成功后旧文案保留在产品的 `copyHistory` 数据中，暂无历史浏览界面。

## DeepSeek 配置

打开“模型设置”，填写服务商实际开通的模型 ID 与 API 密钥。密钥只保存在服务进程内存，重启需重新配置；可用 `DEEPSEEK_API_KEY` 环境变量提供密钥。密钥不会写入数据库、localStorage 或发送回浏览器。

直连官方 `https://api.deepseek.com/chat/completions`。默认模型 `deepseek-flash`，可在设置中填写 `deepseek-v4-pro`。不复用此前中转站密钥；需提供 DeepSeek 官方 API 密钥。

生成前页面说明要发送的文字资料并提示可能的调用费用。后端只发送白名单中的产品资料与关键词，不发送负责人、图片或本地素材路径。新生成文案进入草稿状态并重置审核记录。服务不保证模型不产生事实错误，必须人工审核。

文档来源：https://api-docs.deepseek.com/zh-cn/ （2026-10-26 核对）。图片服务单独接入 APIMart，见后文。

## 数据与验证

数据库：`data/studio.sqlite3`；素材：`data/uploads/`。备份时停止服务后复制整个 `data/` 文件夹。不要仅复制 HTML。此目录已加入 Git 忽略。

运行 `py -3 -m unittest -v test_server.py` 检查存储、版本冲突、来源校验、素材上传、密钥保护和模拟模型响应。测试使用独立临时数据库，不会发起真实模型请求。

## 边界

尚未实现 Excel 导入、用户账号、团队权限、后台生成队列、审核版本锁定、费用统计和刊登服务。角色与审核仍是工作流演示，没有身份验证。模型设置与生成适配已实现，但尚无真实凭据进行端到端调用；示例资料与文案不应直接刊登。团队人数和日产量是设计目标，不是已经验证的性能指标。本地服务不能直接作为 10 人生产系统使用。

## APIMart 图片生成

模型设置中单独配置 APIMart 密钥（或使用 APIMART_API_KEY 环境变量），与 DeepSeek 密钥分开。图片工作台选择 1–4 张上传素材、模型、比例和分辨率，编辑要求后提交单张任务。参考图以 Data URI 发送，合计最多 30 MB。

任务记录保存于 data/image_jobs.sqlite3，刷新或重新打开页面后可继续查询。页面打开期间每 10 秒查询一次未完成任务，关闭页面停止查询，不取消服务商任务。结果仅保存远程链接，可能约 24 小时失效，请及时打开原图另存；尚未实现自动归档或生成图审核绑定。

当前接入 gemini-3-pro-image-preview 与 gemini-3-pro-image-preview-official，支持 1K/2K/4K。端点 /v1/images/generations 与 /v1/tasks/{id}，依据 https://docs.apimart.ai/en/api-reference/images/gemini-3-pro/generation.md 和 https://docs.apimart.ai/en/api-reference/tasks/status.md 。尚未使用真实密钥执行付费端到端测试。

## 产品制作流程补充

Listing 编辑页显示基础资料完整度，支持颜色×尺码组合预览、素材颜色匹配与变体 JSON 导出。子 SKU 仅为排序编号建议，调整颜色尺码顺序会改变编号，正式刊登前需确认固定 SKU。

可手动保存文案版本、按美英站查看历史及恢复。恢复前自动备份当前文案并重置审核。版本记录保存在产品档案 copyHistory 中。

## 密钥持久保存（当前行为）

点击保存后，DeepSeek 和 APIMart 密钥分别使用 Windows DPAPI 按当前 Windows 用户加密，保存在 data/credentials/*.dpapi。服务启动时自动读取，不向浏览器回传。点击清除会删除对应加密文件。旧版仅在内存中的密钥需最后重新保存一次；测试使用临时目录，不接触真实加密文件。更换电脑或 Windows 用户后需要重新配置。环境变量仍可作为启动备用配置；如需彻底清除也请移除对应环境变量。

## 多ASIN竞品挖词

产品Listing编辑页按US/UK分别输入1–5个ASIN，读取公开标题、五点、描述，调用DeepSeek分析关键词和表达结构。词条必须能在实际读取正文找到完整词组，未通过来源验证的模型建议会过滤。关键词不含搜索量，A+、验证码或动态内容可能导致读取不全。

分析保存在产品 competitorResearch[market] 中，支持勾选用词。生成文案时发送选用词及表达结构，真实产品事实仍来自本产品资料；覆盖表按完整词组匹配。不会自动生成文案，需要点击生成按钮。分析及生成均可能收费。当前无亚马逊类目规则实时同步，不保证自动合规；使用者需审核实际文案。
